INFRAESTRUCTURA PERSONAL / OPERACIÓN

Entorno self-hosted para Foundry VTT

Migración · operación · backup · documentación

Diseño y mantenimiento de un entorno autoalojado para Foundry VTT, con separación entre aplicación y datos, migración controlada, estrategia de copias en múltiples destinos y procedimientos de recuperación. El objetivo no es solamente que el servicio levante: es poder reconstruirlo sin depender de memoria o improvisación.

Problema
Mover y mantener un servicio con datos persistentes sin perder continuidad.
Enfoque
Separación de componentes, backups verificables y documentación operativa.
Entorno
